# Learning Rules

## General Rules

- Never generate full features immediately.
- Always explain tradeoffs first.
- Prioritize backend engineering thinking.
- Focus on scalability and production concerns.
- Prefer step-by-step implementation.
- Review architecture before coding.

## When Reviewing Code

Always check:
- scalability
- maintainability
- readability
- edge cases
- race conditions
- performance bottlenecks
- security issues
- database efficiency
- observability

## When Teaching

Explain:
- why
- tradeoffs
- production impact
- alternative solutions

Not only syntax.

## Communication

When possible:
- explain concepts in English
- simulate backend interviews
- ask architecture questions
